## What Is Correct

The feature-flag filter remains the first filter in `Sidebar.tsx`: `/map` and `/pressure` depend on `mapEnabled`, `/nowcast` on `nowcastEnabled`, and `/spray` on `sprayEnabled` before persona rules are applied.

The persona hidden-page count is computed from `flagFiltered`, so pages removed by feature flags are not counted as persona-hidden. This satisfies the precedence requirement that a disabled feature stays hidden regardless of persona or "Show all pages."

The agriculture order matches the requested first-class order when all relevant feature flags are enabled: Dashboard, Spray, Forecast, Nowcast, History, Map, Astronomy, Settings. Pressure is hidden by persona. Filtered-out ordered paths, such as `/spray` when `sprayEnabled=false`, are skipped through the `Map.get()` guard and do not crash or create placeholder items.

`PERSONA_NAV.everyday.order` is empty, and `applyPersonaOrder()` returns the original item list unchanged for an empty order, preserving everyday behavior.

The reversible note behaves as requested for the active persona: it shows the persona-hidden count, toggles to reveal those pages without persisting the override, and provides a "Hide N again" path back. The local `useState` choice also means refresh resets the override.

The header persona switch has a labelled group, visible button text, native buttons, `aria-pressed` state, and titles. Keyboard operation follows native button behavior.
